- New: **update the app without leaving it.** Open the profile menu and tap **Update app**. The app checks GitHub for the newest version, downloads it right there with a progress bar, then shows an **Update** button. Tap it and confirm on Android's normal update screen. No more opening the download website, downloading and scanning a file
- If you are already up to date it tells you so. If you close the window mid-download, the download carries on, and reopening it picks up where it left off. **Cancel** stops it
- The **Update** buttons in the update banner, the **About & updates** box and the "Update required" screen now use the same in-app flow
- **One-time Android permission.** The first time, Android asks you to allow Campus Events to install updates. Turn on **Allow from this source**, go back, and the update continues by itself
- **Safety checks.** The file is only accepted from this project's GitHub releases, its size and checksum are verified, and before the Android screen opens it is checked to be a newer version of this same app signed with the same key
- **Install this version once the old way.** The in-app updater only exists from 3.14.0 on, so this one update still needs the download website. Every update after it can be done inside the app
- Android app only. The website is unchanged. No Firebase rules change, no Worker change, no new secret
